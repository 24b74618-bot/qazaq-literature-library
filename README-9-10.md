# 9–10-апта: Frontend және PHP құрылымы

## Орындалған жұмыстар
- Басты бет, кітаптар каталогы, авторлар беті әзірленді.
- Тіркелу және жүйеге кіру формалары жасалды.
- HTML, CSS және JavaScript қолданылды.
- Адаптивті дизайн қосылды.
- Ортақ header.php және footer.php файлдары include арқылы қосылды.
- Кітаптарды іздеу GET әдісімен орындалады.
- Тіркелу және кіру формалары POST әдісімен өңделеді.
- Сервер жағында енгізілген деректер тексеріледі.
- Шығарылатын мәтін htmlspecialchars() арқылы экрандалады.

## Ескерту
Бұл кезеңде тіркелу/кіру демо-режимде. Пайдаланушы деректерін MySQL-ге сақтау және нақты аутентификация 11-аптада орындалады.

## Іске қосу
1. XAMPP-та Apache қызметін іске қосыңыз.
2. Жоба қалтасын htdocs ішіне көшіріңіз.
3. Браузерден http://localhost/qazaq-literature-library/ мекенжайын ашыңыз.
