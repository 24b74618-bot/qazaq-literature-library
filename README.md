# qazaq-literature-library
Қазіргі цифрлық технологиялар дамыған кезеңде әдеби мұраларды электронды форматта сақтау және кеңінен тарату маңызды.
# Қазақ әдебиеті онлайн кітапханасы
### Qazaq Literature Library

## Жоба туралы
Қазақ әдебиеті онлайн кітапханасы – қазақ әдебиетіндегі көркем шығармаларды, ақын-жазушылардың өмірбаянын және әдеби мұраларды бір платформаға жинақтауға арналған веб-қосымша.

Жобаның басты мақсаты – қазақ әдебиетін цифрлық форматта қолжетімді ету, оқырмандардың кітап іздеуін жеңілдету және ұлттық әдеби мұраны насихаттау.

## Жобаның міндеттері
- Қазақ әдебиеті шығармаларының электронды каталогын жасау;
- Ақын-жазушылар туралы мәліметтер ұсыну;
- Шығармаларды жанр бойынша топтастыру;
- Кітаптарды іздеу және сүзгілеу;
- Пайдаланушыларды тіркеу және жүйеге кіргізу;
- Таңдаулы кітаптарды сақтау;
- Әкімшіге кітаптарды басқару мүмкіндігін беру.

## Қолданылатын технологиялар
- HTML – веб-беттің құрылымы;
- CSS – веб-сайттың дизайны;
- JavaScript – интерактивті элементтер;
- PHP – серверлік бағдарламалау;
- MySQL – дерекқорды басқару;
- PDO – PHP пен MySQL арасындағы байланыс;
- GitHub – жобаның кодын сақтау және нұсқаларын бақылау.

## Негізгі бөлімдер
1. Басты бет
2. Кітаптар каталогы
3. Авторлар
4. Кітап туралы толық ақпарат
5. Тіркелу және жүйеге кіру
6. Пайдаланушының жеке кабинеті
7. Әкімші панелі

## Дерекқор құрылымы
Жобада `qazaq_library` атты MySQL дерекқоры қолданылады.

Негізгі кестелер:
- users
- authors
- categories
- books
- favorites

## Қауіпсіздік
- Құпиясөздерді password_hash() арқылы хэштеу;
- Құпиясөзді password_verify() арқылы тексеру;
- PDO және prepared statements қолдану;
- htmlspecialchars() арқылы XSS шабуылдарынан қорғану;
- Сессиялар арқылы пайдаланушыны авторизациялау;
- Әкімші мен қарапайым пайдаланушы құқықтарын бөлу.

## Жобаны іске қосу
1. XAMPP бағдарламасын орнату.
2. Apache және MySQL қызметтерін іске қосу.
3. Жоба қалтасын `htdocs` ішіне орналастыру.
4. phpMyAdmin арқылы `qazaq_library` дерекқорын құру.
5. `database/qazaq_library.sql` файлын импорттау.
6. `config/database.php` файлында дерекқорға қосылу параметрлерін көрсету.
7. Браузерден `http://localhost/qazaq-literature-library/` мекенжайын ашу.
